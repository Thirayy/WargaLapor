# WargaLapor - Platform Pengaduan Infrastruktur Publik
WargaLapor adalah platform pengaduan masyarakat berbasis digital yang transparan dan interaktif untuk melaporkan kerusakan infrastruktur publik seperti jalan berlubang dan lampu jalan mati.

## Tech Stack
- **Framework:** Next.js (App Router, TypeScript)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **State & Storage:** React Hooks & Browser LocalStorage (Frontend-Only Simulation)
